# Video Flow

从主题或文稿制作中文讲解视频的 Codex Skill。先联网核实资料、保存可入镜的原始证据并确认文案；再由用户选择声音形式与视觉风格，最后用代码制作、渲染和验收视频。画面可使用有来源的静态图片，不使用 AI 生成视频镜头。

## 流程

1. 调研主题，写逐字稿，保存来源和可能入镜的真实截图。
2. 确认文案，并选择配乐字幕或 API 配音，以及清爽纪实、纸感拼贴、深色技术台中的一种视觉风格。
3. 按已选方案制作统一时间线、代码画面、声音和字幕，检查实际 MP4，交付成片与可编辑工程。

详细规则见 [SKILL.md](SKILL.md)。`references/` 存放按阶段读取的研究、制作和 MiniMax 配音说明；`agents/openai.yaml` 是 Codex 中的展示与调用元数据。

## 本地使用与维护

本仓库根目录就是 Skill 目录，调用名为 `$video-flow`。当前 Codex 安装目录中另有一份可用副本；修改本仓库后，需要同步到安装目录才会影响该副本。修改后运行：

```bash
python3 ~/.codex/skills/.system/skill-creator/scripts/quick_validate.py .
```

API Key 只在运行时从安全凭据来源读取，不提交到仓库，也不写入视频工程或日志。测试视频、截图和旁白素材应放在独立输出目录，并在公开前逐项检查来源与使用条件。

本仓库目前仅作本地版本管理，尚未选定开源许可证或发布。
